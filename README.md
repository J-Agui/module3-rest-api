# module3-rest-api

To run this application in eclipse, please open the source folder within a springboot application and run the file named 'CampusIdeasApplication.java' as a Java Application.

GET requests generally have the sole duty of retrieving and handing the data to whichever function or individual needs it. POST requests have the duty of taking data it has
received and updating whatever data storage it was assigned to update, like a database.
